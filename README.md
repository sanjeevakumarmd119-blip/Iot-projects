# 🌐 IoT & Arduino Projects

Welcome to my **IoT & Arduino Projects Repository!** 🚀

This repository is a collection of projects developed using Arduino, ESP32, sensors, electronic components, and IoT technologies.

The projects range from basic Arduino experiments to practical IoT-based applications. Each project focuses on learning embedded systems, sensor integration, automation, and real-world problem-solving.

## 📂 Projects

### 🌱 1. Smart Plant Care System
An IoT-based plant monitoring and automatic watering system that monitors soil moisture, temperature, and humidity to maintain suitable growing conditions.

**Components:**
- ESP32 / Arduino
- Soil Moisture Sensor
- DHT22 Sensor
- OLED Display
- Relay Module
- Water Pump

**Features:**
- Real-time soil moisture monitoring.
- Temperature and humidity monitoring.
- Automatic watering system.
- Plant-specific moisture thresholds.

### 💡 2. Automatic Street Light System
An automatic lighting system that switches street lights ON or OFF depending on surrounding light intensity.

**Components:**
- Arduino Uno
- LDR Sensor
- LEDs
- Resistors

**Features:**
- Automatic light detection.
- Energy-saving operation.
- Automatic LED control.

### 🚨 3. Smart Obstacle Detection System
An Arduino-based system that detects nearby objects using an ultrasonic sensor.

**Components:**
- Arduino Uno
- Ultrasonic Sensor (HC-SR04)
- Buzzer
- LEDs

**Features:**
- Distance measurement.
- Obstacle detection.
- Buzzer alerts when objects approach.

### 🔥 4. Fire and Gas Detection System
A safety monitoring system that detects smoke or combustible gases and provides an alert.

**Components:**
- Arduino Uno
- MQ-2 Gas Sensor
- Buzzer
- LEDs

**Features:**
- Gas and smoke detection.
- Audible warning alerts.
- Real-time sensor monitoring.

### 🌡️ 5. Temperature and Humidity Monitoring System
A basic environmental monitoring project that measures surrounding temperature and humidity.

**Components:**
- Arduino Uno
- DHT11 / DHT22 Sensor
- LCD / OLED Display

**Features:**
- Temperature measurement.
- Humidity monitoring.
- Real-time display of sensor readings.

### 🚶 6. Automatic Motion Detection System
A security-based project that detects human movement using a PIR motion sensor.

**Components:**
- Arduino Uno
- PIR Motion Sensor
- Buzzer
- LEDs

**Features:**
- Motion detection.
- Automatic alarm activation.
- Basic security monitoring.

### 💧 7. Automatic Water Level Indicator
A water monitoring system that detects the water level in a tank and indicates the available water level.

**Components:**
- Arduino Uno
- Water Level Sensor
- LEDs
- Buzzer

**Features:**
- Water level monitoring.
- Level indication using LEDs.
- Alert when the tank reaches a specified level.
